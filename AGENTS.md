# Todo App

## commands
- Tests: `npm run tests: unit -- --run`
- Lint: `npm run lint`. it fixes what it can, so chek the diff after running it.

## How this project works
- All todo state lives in a `App.vue`. Components get props and emit events, Don't add a store.
- Plan CSS in scoped style blocks. No CSS frameworks or UI libraries.
- Ask before adding any dependency.

## Before you say you're done
- New behaviour has a tes in `src/__tests__`.
- Run the tests and the lint, and show me the output.
